# AL LABIB — Personal Portfolio

A responsive, single-page personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Open this folder in Visual Studio Code.
2. Add your portrait as `images/profile.jpg`.
3. Add your CV PDF as `cv/resume.pdf`.
4. Replace placeholder GitHub and LinkedIn links in `index.html`.
5. Open `index.html` with the VS Code Live Server extension.

## Customize before publishing
- Confirm every CV detail is still current.
- Replace `+880 1748******` with the public phone number you want to show, or remove that contact row.
- Replace the `href="#"` project links with real repository/demo links.
- Update the social profile links.
- The contact form uses `mailto:` and opens the visitor's email application. It does not send messages through a server.
- Lucide icons and Google Fonts are loaded from online CDNs, so those features need an internet connection.

## Project structure
- `index.html` — page content
- `css/style.css` — layout, theme, responsive styles
- `js/script.js` — navigation, reveal animation, active section, contact form
- `images/` — profile image and project images
- `cv/` — downloadable resume PDF
